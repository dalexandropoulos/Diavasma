# Diavasma 📖

> Ένας ήσυχος, 100% offline χώρος ανάγνωσης, συγκέντρωσης και οργάνωσης βιβλίων & άρθρων — χωρίς διαφημίσεις, χωρίς παρακολούθηση (tracking), χωρίς εξαρτήσεις από servers.

---

## ✨ Κύρια Χαρακτηριστικά (Features)

- **📚 Υποστήριξη Πολλαπλών Μορφών:** Άμεση ανάγνωση EPUB, PDF (με offline reflow engine), Markdown (.md), απλού κειμένου (.txt) και αρχείων ήχου (.mp3).
- **🌐 Λήψη Άρθρων από URL & Custom Selectors:** Εισαγωγή άρθρων με έξυπνη εξαγωγή περιεχομένου και δυνατότητα ορισμού εξειδικευμένων CSS selectors ανά ιστοσελίδα.
- **⚡ 100% Offline PWA (Progressive Web App):** Πλήρως λειτουργικό χωρίς σύνδεση internet. Μπορεί να εγκατασταθεί σε Android, iOS, Windows και macOS σαν αυτόνομη εφαρμογή μέσω του Browser.
- **🎨 6 Επιμελημένα Θέματα & Τυπογραφία:** Χαρτί (Paper), Θερμό (Warm), Φασκόμηλο (Sage), Σχιστόλιθος (Slate), Νύχτα (Night) και AMOLED, με επιλογή 8 ποιοτικών γραμματοσειρών και υποστήριξη custom fonts (.ttf, .otf, .woff2).
- **🎧 Ηχοτοπία & Μουσική:** Ενσωματωμένοι χαλαρωτικοί ήχοι (λευκός θόρυβος, βροχή, καφέ) και αναπαραγωγή τοπικών αρχείων ήχου.
- **⏱️ Pomodoro Screensaver:** Χρονόμετρο εστίασης με δυναμικό screensaver κλεψύδρας κατά τα διαλείμματα.
- **📊 Στατιστικά Ανάγνωσης & Habit Tracker:** Καταγραφή χρόνου και σερί με γραφήματα δραστηριότητας (heatmap τύπου GitHub) και δημιουργία καρτών κοινοποίησης (share cards).
- **🗣️ Αυτόματη Εκφώνηση (Text-to-Speech):** Ανάγνωση κειμένου με φυσικές φωνές συστήματος και επισήμανση της τρέχουσας παραγράφου.
- **🌍 10 Γλώσσες:** Πλήρης μετάφραση σε Ελληνικά, Αγγλικά, Ισπανικά, Γαλλικά, Γερμανικά, Ρωσικά, Κινεζικά, Ιαπωνικά, Χίντι και Πορτογαλικά.

## 🚀 Εγκατάσταση ως Εφαρμογή (PWA)

1. Ανοίξτε το `Diavasma.html` (ή το URL του GitHub Pages) σε έναν σύγχρονο browser (Chrome, Edge, Safari, Brave, Firefox).
2. Πατήστε το κουμπί **«Εγκατάσταση εφαρμογής»** στη γραμμή διευθύνσεων ή από το μενού **Περισσότερα (⋯) → Εγκατάσταση Diavasma**.
3. Στο iOS (Safari): Πατήστε το κουμπί **Κοινοποίηση (Share) → Προσθήκη στην οθόνη αφετηρίας (Add to Home Screen)**.

## 🌐 Ανέβασμα & Φιλοξενία στο GitHub Pages

1. Δημιουργήστε ένα νέο αποθετήριο (repository) στο GitHub.
2. Ανεβάστε όλα τα αρχεία του φακέλου:
   - `Diavasma.html` (κεντρική εφαρμογή)
   - `index.html` (αυτόματη ανακατεύθυνση στο Diavasma.html)
   - `sw.js` (service worker για offline λειτουργία)
   - `manifest.json` (ρυθμίσεις PWA)
   - `icon.svg` (εικονίδιο εφαρμογής)
   - `pdf.min.js` & `pdf.worker.min.js` (μηχανή PDF)
   - `README.md`
3. Στις ρυθμίσεις του αποθετηρίου (**Settings → Pages**):
   - Επιλέξτε **Deploy from a branch**.
   - Διαλέξτε το branch `main` (ή `master`) και τον φάκελο `/ (root)`.
   - Πατήστε **Save**.
4. Σε λίγα λεπτά η εφαρμογή σας θα είναι προσβάσιμη παγκοσμίως και εγκαταστάσιμη στο `https://<username>.github.io/<repository-name>/`.

## 🔒 Ιδιωτικότητα (Privacy First)

Το Diavasma δεν συλλέγει, δεν αποθηκεύει και δεν μεταδίδει κανένα προσωπικό δεδομένο, ιστορικό ή αρχείο σε εξωτερικούς διακομιστές. Όλα τα βιβλία, τα κείμενα, οι σημειώσεις και οι προτιμήσεις παραμένουν 100% τοπικά στη συσκευή σας (`localStorage` & `IndexedDB`).
